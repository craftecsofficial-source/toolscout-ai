Vectr is a good pick for students, small businesses and casual designers who want a simple browser-based SVG editor and logo maker, with AI extras as an option; skip it if you need professional-grade path tools, offline work or predictable AI pricing. It is operated by Pixlr Pte Ltd, per the site footer. The editor handles shapes, pen and path tools, layers and real-time co-editing through a shared link, with export to SVG, PNG and JPG and cloud sync across devices. The site now also advertises AI features: logo maker, text-to-SVG, raster-to-vector conversion, background remover, image-to-image, inpainting, outpainting, object removal, upscaling, face swap and a video generator. Opening EPS, AI, PDF and SVGZ files uses credits. We could not retrieve a pricing page today, so what is free versus paid, and what credits cost, is unverified; check vectr.com before relying on the free claim.

Best for

Good for beginners, students, freelancers and small teams who want quick logos and simple vector graphics with live collaboration. Not for professional illustrators needing deep path editing or reliable EPS/AI/PDF interchange, anyone who must work fully offline, or buyers who need clear AI credit costs up front.

Key features

01

AI Vectorizer & Raster-to-Vector Conversion

Converts JPG, PNG, and other raster images into editable, scalable SVG vector files, including photo-to-vector silhouette conversion.

02

Text-to-Vector / Text-to-Image

Generates fully editable SVGs with clean paths and layers from text prompts, plus a separate premium image generator for raster (JPG/PNG) output.

03

AI Background Remover

One-click removal of image backgrounds to create transparent PNGs for product photos, profile pictures, and marketing assets.

04

AI Logo Maker

Generates professional, editable logo concepts from prompts or templates, aimed at beginners without design training.

05

Real-Time Collaboration

Multiple users can co-edit the same vector project live via a shared URL, with an integrated chat panel for feedback.

06

Image Editing Suite

Includes inpainting, outpainting, object removal, auto-enhance upscaling, and AI face swap for touching up and extending images.

07

Cross-Platform Sync

Projects save to the cloud and stay accessible across the web app and native desktop apps on Windows, macOS, Linux, and Chromebook.

08

Multi-Format Export

Export finished designs as SVG, PNG, or JPG; opening premium formats like EPS, AI, PDF, and SVGZ consumes credits.

Pros and cons

Pros

  • Simple interface with pen, shape, fill, gradient and layer tools, so beginners can produce clean SVG quickly.
  • Real-time collaboration through a shared link suits classrooms and small teams.
  • Runs in the browser and has desktop apps, with cloud sync across devices.
  • One workspace combines a manual vector editor with AI generation and raster-to-vector conversion, reducing app switching.

Cons

  • Pricing is unclear: the site mentions credits and a special offer but we could not verify costs, so budgeting for AI use is guesswork.
  • Projects live in the cloud, so a connection is generally needed; we could not confirm any full offline mode.
  • Opening common professional formats (EPS, AI, PDF, SVGZ) costs credits, which is awkward if you exchange files with designers.
  • A lightweight editor: complex illustration and precision work are better served by Illustrator or Inkscape.

Frequently asked questions

Is Vectr free?

Its page metadata calls it a free vector editor, but we could not retrieve a plan table to confirm limits. AI tools and some file imports use credits.

Which files can Vectr open and export?

Export is SVG, PNG and JPG. It opens SVG, PNG, JPG, and EPS, AI, PDF and SVGZ, the last four requiring credits per the site.

Can I collaborate in real time?

Yes, the site advertises real-time co-editing and shared workspaces.

Who runs Vectr?

The site footer names Pixlr Pte Ltd.

Is it a replacement for Illustrator?

Only for simple logos and graphics. It does not target advanced professional vector work.
