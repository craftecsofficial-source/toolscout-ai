Ishi is a good pick for individuals who want a privacy-first desktop AI agent to tidy files and automate document chores, and who prefer a one-time license over a subscription; skip it if you need a polished, proven product, team features, or a settled price. It is a desktop app from Ishi Labs that organizes folders, extracts PDF data into spreadsheets and renames files by content, showing a preview of every change before it runs.

Work goes through a Draft, Plan, Simulate, Execute flow with a diff-style Ghost File preview. File tasks run locally, and heavier or scheduled work can be handed to the separate AgenticFlow cloud only when you approve it. You can bring your own Claude, OpenAI, Google or local model keys.

Pricing needs care: the site shows Pro at $49 one-time as a beta offer valid until February 28, 2026, with $99 as the standard price. That date has passed, so we could not verify the current price. No independent reviews were found, and the dedicated pricing page could not be fetched.

Best for

Good for individuals and small teams comfortable bringing their own API keys and paying once. Not for large teams needing admin controls or SLAs, people who want a mature, widely reviewed product, anyone who needs guaranteed Linux support today, or buyers who need a firm, verified current price.

Key features

01

Glass Box Simulation

Every action is planned and shown as a translucent 'Ghost File' preview — a diff of exactly what will change — before Ishi executes it, so users approve the plan rather than the AI acting blindly.

02

Local File Organization

Organizes messy folders (e.g., a Downloads folder), extracts data from PDFs into spreadsheets, and renames files based on content, using local inference so files don't leave the device.

03

AgenticFlow Cloud Bridge

For tasks needing heavier or longer-running reasoning — multi-step workflows, 24/7 scheduled automation, multi-agent orchestration, or external integration triggers — Ishi can hand off to the AgenticFlow cloud platform on explicit approval.

04

Bring Your Own Key (BYOK)

Users connect their own Claude, OpenAI, Google, or local model API keys at no markup, or use the built-in Pixel ML OpenRouter option for pay-as-you-go access without juggling multiple provider keys.

05

Cross-Platform Native Apps

Ships as native desktop software for macOS (Apple Silicon and Intel) and Windows, with Linux support in progress, plus a dedicated Obsidian plugin for knowledge-base workflows.

06

Multi-Agent Sessions

Runs multiple isolated AI agent sessions in parallel so different projects or file-organization tasks can proceed simultaneously without interfering with each other.

07

Skill Marketplace

Pro license holders get access to 100+ premium prebuilt automation 'skills' that can be applied to common file, document, and workflow tasks.

08

One-Time Licensing

Sold as a lifetime license rather than a subscription — Ishi's own pricing comparison claims a 5-year cost of $49 versus $1,200+ for typical $20/month SaaS AI subscriptions.

Pros and cons

Pros

  • One-time license rather than a monthly fee, which is unusual among AI tools and cheaper over several years if the $99 list price holds.
  • Preview-before-execute flow means files are not renamed or moved without approval.
  • Local-first design keeps file work on your machine unless you approve cloud delegation.
  • BYOK with Claude, OpenAI, Google or local models avoids lock-in to one provider.

Cons

  • Public beta with no independent reviews found.
  • Pricing display is stale: the beta price deadline of Feb 28, 2026 is past and the current price is unverified.
  • Cloud-powered features depend on the separate AgenticFlow service.
  • Linux support is inconsistent on the site, and a dedicated pricing page could not be fetched.

Frequently asked questions

How much does Ishi cost?

Free tier at $0 with your own API keys. Pro is a one-time license: $49 beta offer (stated valid until Feb 28, 2026, now past) or $99 standard. The current price is unverified — check ishi.so.

Is there a free plan?

Yes, Ishi Free includes the desktop app, simulation and diff preview, local data and BYOK, plus a $1 Pixel ML trial credit.

Does my data leave my computer?

File tasks run locally by default; the site says cloud calls happen only when you explicitly approve delegating a task.

Which platforms are supported?

macOS (Apple Silicon and Intel) and Windows now. Linux is listed as coming soon in one place and supported in others, so unverified.
