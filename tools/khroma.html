Khroma is a free web tool that generates color palettes using a machine learning model trained specifically on each user's preferences. New users start by selecting a set of colors they like from a large sample, which trains a personal AI model used to generate an endless, scrollable feed of palette combinations aligned with that taste.

Rather than producing generic or fully random palettes, Khroma's core idea is that the more relevant a palette is to a designer's actual aesthetic, the more useful it becomes, avoiding the noise of unrelated color suggestions common in simpler generators. Users can view palettes as flat color swatches, gradients, text/background combinations, or applied to sample layouts.

Built as an independent, free micro-tool rather than a commercial product, Khroma has become a popular quick-reference utility among designers looking for fast color inspiration without navigating a full design application.

Best for

Khroma is ideal for designers, developers, and hobbyists who want fast, personalized color inspiration for websites, apps, or branding without paying for or learning a full design tool. It works well as a lightweight companion to design software like Figma rather than a replacement. Teams needing shared color libraries or brand governance should look at more structured design system tools.

Pros and cons

Pros

  • Zero cost and no account creation removes any friction to start generating palettes immediately
  • Personal AI training produces palettes that better match individual taste than purely random generators
  • Multiple visualization modes (gradient, text, mockup) help designers judge real-world usability of a palette
  • Simple, distraction-free interface focused entirely on the color discovery task

Cons

  • Lacks project folders, tagging, or organization systems for managing many saved palettes
  • No collaboration features for sharing curated palettes with a team
  • Export is limited to hex codes rather than integration with design files or style guides
  • Preferences are trained once per session/browser and don't dynamically evolve without retraining

Frequently asked questions

Is Khroma really free?

Yes, Khroma is entirely free with no paid tiers, ads, or account requirement.

How does Khroma personalize palettes?

It trains a small AI model based on colors the user selects as liked during an initial onboarding step.

Can I export palettes to design tools?

Khroma provides hex codes that can be manually copied into tools like Figma, Adobe products, or CSS.

Do I need to create an account?

No account is required; preference training is tied to the browser session.

Can I retrain my preferences?

Users can redo the initial color-liking process to refresh the personalized model.

Does Khroma work on mobile?

Yes, it works in any modern web browser, though the experience is optimized for desktop use.
