Skyvern is a strong choice for developers and operations teams who need to automate real websites that have logins, CAPTCHAs and layouts that change; skip it if you only need a simple, stable scraper (a normal script is cheaper and faster) or a visual app builder. It runs a browser agent that looks at the page, decides what to click or type, and returns structured data or completed forms.

You can describe the task in a chat copilot, upload an SOP, demonstrate it once, use a visual builder, or code against the Python/TypeScript SDK. Each run produces a summary of the actions taken, which helps debugging. The project is open source (about 23,000 GitHub stars per the site) and can be self-hosted with Docker. The vendor also claims SOC 2 Type II, HIPAA compliance, 10M+ workflows run and a 99.9% uptime SLA; these are self-reported.

Pricing is credit-based: roughly 170 actions are included in the one-time free credits, about 1,200 a month on Hobby and about 6,200 on Pro. Because AI steps consume credits, long multi-step workflows get expensive, so run a pilot on your target site before committing.

Best for

Good for developers and ops or finance teams automating portal tasks such as invoice downloads, compliance forms and data pulls behind logins, especially on sites that change often or lack an API. Not for people wanting a no-code app or website builder, teams with simple stable scraping needs where a plain script is cheaper, or low-budget users who need 2FA or team workspaces without paying $149/mo.

Key features

01

Vision-based automation

Identifies elements by looking at the page plus LLM reasoning, so small layout changes do not break the workflow the way fixed selectors do.

02

CAPTCHA and 2FA handling

Solves CAPTCHAs without a third-party service (basic on Hobby, advanced on Pro) and handles TOTP two-factor logins on Pro and up.

03

Multiple ways to build

Chat copilot, SOP upload, one-time demonstration, visual builder, or Python/TypeScript SDK.

04

Data extraction

Pulls data from pages into JSON or CSV when no API exists.

05

Run explanations

Each run includes a summary of the actions taken and the reasoning behind them.

06

Proxies and geo-targeting

Country-level targeting on lower tiers; residential proxy and city-level targeting on Pro.

07

Developer tooling

SDKs, webhooks, MCP support and Docker self-hosting.

08

Integrations

Connects to Zapier, Make, Clay, n8n and Workato.

Pros and cons

Pros

  • Looking at the page instead of relying on selectors targets the most common reason browser automations fail: UI changes.
  • 2FA/TOTP and CAPTCHA handling covers logins that block many simple agents, though 2FA requires the Pro plan.
  • Open source and self-hostable, so teams can inspect the code and run it on their own infrastructure.
  • Several build paths let non-developers start in a copilot or builder and developers move to SDKs.
  • Run summaries give an audit trail of what the agent did, useful for debugging and compliance review.
  • Enterprise tier lists HIPAA compliance and a SOC-2 report for regulated use.

Cons

  • Credits are consumed per AI step and the free allowance is one-time (about 170 actions), so you cannot run meaningful volume without paying.
  • The pricing page does not state the price of extra credits or overage, so cost at scale is hard to predict.
  • 2FA/TOTP, team workspaces and residential proxy are locked to Pro ($149/mo); Hobby users needing just one of these must jump 5x.
  • AI-driven steps are slower and costlier than a deterministic script, and success on a given site is not guaranteed; test before relying on it.
  • Uptime, user and compliance figures are the vendor's own claims; we found no independent review-site ratings to verify them.
  • Not a general app builder; it only automates existing websites.

Frequently asked questions

Is there a free plan?

Yes: 5,000 one-time credits, about 170 actions, with 1 concurrent run and no card required. It is meant for testing, not ongoing use.

Which plan do I need for 2FA/TOTP logins?

Pro at $149/month. Hobby ($29/mo) includes only the basic CAPTCHA solver and stored credentials.

How is Skyvern different from Playwright or Selenium?

Those run fixed selector-based scripts that break when pages change. Skyvern uses vision and an LLM to decide actions on each run, trading some speed and per-run cost for resilience.

Can I self-host it?

Yes. The project is open source and supports Docker self-hosting, so you can run it on your own infrastructure.

What does an extra credit cost?

The pricing page does not list overage or extra-credit rates; check the official pricing page or ask sales.
