Remove.bg still works today but is a poor choice to adopt: the owner, Canva, says the standalone website will no longer be available from 1 December 2026 at 9:00am CET, with background removal moving to Canva. It is fine for a quick cutout before then, but skip it if you want a tool you can build a workflow, API integration or credit stock around. It removes the background from a photo automatically in about five seconds, aimed at product shots, car listings, headshots and transparent PNGs.

Best for

Who it is for: anyone who needs a few background removals before December 2026 and does not mind switching afterwards. Who it is not for: teams planning a long-term workflow, API integration or large credit purchase on remove.bg itself; consider Canva, Leonardo.Ai, or an alternative instead.

Key features

01

Automatic background removal

One-click removal; the site lists uploads up to 22 MB and output up to 50 megapixels.

02

Apps and plugins

Listed options include an Android app, Windows/Mac/Linux software and a Photoshop extension. What happens to them after 1 December 2026 is not stated on the pages we read.

03

API

A developer API with the first 50 calls each month free. The API page says background removal moves to Leonardo.Ai, which is also part of Canva; whether endpoints keep running on the same schedule was not stated.

04

Move to Canva

The site says background removal is moving to Canva, which is a full design suite, so it becomes one step in a larger tool.

Frequently asked questions

Is Remove.bg shutting down?

The standalone website will no longer be available from 1 December 2026 at 9:00am CET, according to the site, which says background removal is moving to Canva.

What happens to my credits?

A third-party report quoting remove.bg says unused pay-as-you-go credits expire on 1 December 2026. Check remove.bg's FAQ before buying or relying on credits.

Will the API keep working?

The API page says background removal moves to Leonardo.Ai, but did not clearly state whether endpoints continue on the same date. Enterprise contracts are reported to be unaffected.

Is it free?

The site promotes free background removal, and the API has 50 free calls per month. Free-tier limits and paid prices could not be verified today.

Who owns it?

It is a brand of Canva Austria GmbH.
