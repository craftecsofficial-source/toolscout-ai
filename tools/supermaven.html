Supermaven was founded in 2024 by Jacob Jackson, the creator of Tabnine — one of the earliest deep-learning code completion tools, which he built as a University of Waterloo student before selling it to Codota in 2019. After an internship at OpenAI, Jackson built Supermaven around a specific bet: that completion quality on large codebases depends heavily on context window size and inference speed, not just model size. Supermaven launched with a 300,000 token context window and later expanded it to 1 million tokens on the Pro tier, positioning it as one of the largest context windows available in an AI coding assistant at the time. The company raised a $12 million round led by Bessemer Venture Partners with angel investment from OpenAI co-founder John Schulman and Perplexity co-founder Denis Yarats.

In November 2024, Supermaven was acquired by Anysphere, the company behind the AI-native code editor Cursor. It continues to operate as a separate, lightweight completion extension for VS Code, JetBrains IDEs, Neovim, Vim, Emacs, and Zed, rather than being folded directly into Cursor's editor. This makes it appealing to developers who want fast completions inside whatever editor they already use, rather than adopting an entirely new IDE. Supermaven's product surface is deliberately narrow compared to full agentic IDEs: it focuses on completions and an in-editor chat feature rather than autonomous multi-file agents or terminal execution.

Best for

Supermaven fits individual developers and small teams who want the fastest possible inline completions and are happy keeping their current editor setup rather than adopting a new AI-native IDE. It's a weaker fit for teams that need autonomous multi-file agent workflows, terminal execution, or heavy enterprise reporting, since those capabilities live in adjacent products like Windsurf or Cursor rather than in Supermaven itself.

Key features

01

High-speed completions

Supermaven is built for very low latency inline suggestions, aiming to keep pace with fast typists rather than introducing noticeable lag.

02

1 million token context window

The Pro plan expands context to 1 million tokens, letting the model reference far more of a large codebase when generating suggestions than most competing completion tools.

03

In-editor AI chat

A built-in chat interface lets developers ask questions or request changes using models like Claude and GPT-4o without leaving the editor, funded by a monthly credit allowance.

04

Style adaptation

On Pro, Supermaven adapts its suggestions to match an individual developer's existing coding conventions and patterns.

05

Broad editor support

Official extensions cover VS Code, JetBrains IDEs, Neovim, Vim, Emacs, and Zed, so it can be added to most existing developer setups.

06

Functional free tier

The Free plan isn't a crippled trial — it offers real fast completions and large-codebase support, with the 1M context window and chat credits reserved for Pro.

Pros and cons

Pros

  • Independent and user reports consistently describe Supermaven's completions as faster than GitHub Copilot and Cursor's Tab completion, which matters directly for flow-state coding.
  • The 1 million token context window on Pro lets the model draw on far more of a large monorepo than typical completion tools, improving suggestion relevance in big projects.
  • At $10/month flat, Pro pricing undercuts many rival AI coding assistants while still including chat credits and style adaptation.
  • Because it's a narrow-scope extension rather than a full IDE, it's easy to add to an existing VS Code or JetBrains setup without disrupting other tooling or workflows.
  • The free tier is genuinely usable day to day, not a stripped-down demo, which lowers the barrier for developers to try it before paying.

Cons

  • Since its November 2024 acquisition by Anysphere (Cursor's parent company), Supermaven's long-term positioning as a standalone product is uncertain — it could eventually be merged into Cursor's own completion engine.
  • It intentionally does not offer the autonomous multi-file agentic editing found in Windsurf, Cursor's agent mode, or GitHub Copilot Workspace, so teams wanting a full agent-driven workflow will need a separate or additional tool.
  • There's no web-based or mobile IDE version; it only works as an extension inside supported desktop editors.
  • Public review coverage is thin — no rating data was found on G2 or Capterra at the time of research, making it harder to independently verify enterprise-scale satisfaction versus better-documented competitors.

Frequently asked questions

Is Supermaven free?

Yes, the Free tier offers real fast completions and large-codebase support at $0/month, with the 1M token context window and chat credits reserved for the $10/month Pro plan.

Who owns Supermaven?

Supermaven was founded by Jacob Jackson (creator of Tabnine) in 2024 and was acquired by Anysphere, the maker of the Cursor code editor, in November 2024. It still operates as a separate product.

Which editors does Supermaven support?

Official extensions are available for VS Code, JetBrains IDEs, Neovim, Vim, Emacs, and Zed.

How large is the context window?

Up to 1 million tokens on the Pro plan; the Free tier uses a smaller context window.

Does Supermaven include AI chat, not just completions?

Yes, Pro and Team plans include $5/month in Supermaven Chat credits to use models like Claude and GPT-4o directly in the editor.

Is there a team plan?

Yes, the Team plan is $10 per user per month with unlimited team members and centralized billing and user management.
