Amazon Q Developer is AWS's generative AI assistant for software development, designed to work across the entire software development lifecycle rather than just inline code completion. It plugs into major IDEs (VS Code, JetBrains, Visual Studio) and the command line, and is also embedded directly in the AWS Management Console, where it can answer account-level questions, diagnose errors, and generate AWS CLI commands. Beyond standard code suggestions, Q Developer includes autonomous agentic capabilities: given a natural-language task, it can generate an implementation plan, create a new branch, make multi-file changes, and propose a pull request for review — covering tasks like implementing a feature, refactoring code, or upgrading dependencies. A standout capability is its automated code transformation for legacy Java and .NET application upgrades, which can modernize large codebases with far less manual rewrite effort than doing it by hand.

Amazon Q Developer's pricing follows AWS's usage-based philosophy: a genuinely usable perpetual Free Tier (50 agentic requests per month, access to the latest Claude models, and 1,000 lines of code per month for Java transformation) sits alongside a Pro Tier at $19/user/month that raises those limits, adds identity center support with admin dashboards, and includes IP indemnity — important for enterprises worried about copyright exposure from AI-generated code. Code transformation overages beyond the Pro tier's pooled 4,000 LOC/user/month allowance are billed at $0.003 per line. Because Amazon Q Developer is deeply woven into AWS services — including a dedicated integration with AWS's pricing APIs for real-time cost insight — it is most valuable to teams already building on AWS, and comparatively less compelling for teams working in non-AWS environments where its account-level and cloud-specific features go unused. On G2, it holds a strong 4.6/5 rating from 51 reviews as of August 2026, with reviewers praising its context-aware, AWS-grounded suggestions but noting it can feel generic or less useful outside AWS-specific workflows.

Best for

Amazon Q Developer is the clear choice for engineering teams already building on AWS who want an assistant that understands their account, services, and infrastructure — particularly valuable for large-scale Java or .NET modernization projects. It's a weaker fit for teams working entirely outside the AWS ecosystem, who would get more general-purpose value from a cloud-agnostic assistant.

Pros and cons

Pros

  • The Free Tier is a genuine perpetual offering, not a time-boxed trial — 50 agentic requests and 1,000 lines of code for transformation every month at no cost.
  • Deep, arguably unmatched AWS integration: Q Developer can answer account-specific questions, diagnose console errors, and generate CLI commands, going well beyond what general-purpose coding assistants offer for AWS workloads.
  • Automated Java/.NET application transformation is a genuinely differentiated capability for teams facing large legacy modernization projects, cutting manual migration effort significantly.
  • Direct connection to AWS pricing APIs lets developers get accurate, current cost estimates without leaving their workflow.
  • G2 reviewers give it a strong 4.6/5 rating (51 reviews), specifically calling out context-aware suggestions and AWS best-practice guidance as standout strengths.

Cons

  • Effectiveness drops for codebases and workflows not tied to AWS — several G2 reviewers note it feels "generic" or less useful outside AWS-specific use cases.
  • The Free Tier's 50 agentic requests per month is low for developers who want to use it as a daily primary coding assistant, pushing regular users toward the Pro tier.
  • Code transformation overage pricing ($0.003 per line beyond the pooled 4,000 LOC/user/month) can create unpredictable bills for teams running large-scale modernization projects.
  • Canceling a Pro subscription mid-month still incurs the full month's charge, an AWS billing quirk that can catch teams off guard.
  • As with many AWS products, granular admin and subscription management (Identity Center setup, per-user billing fractions) has a learning curve for teams new to AWS's billing model.

Frequently asked questions

Is Amazon Q Developer free?

Yes, there is a perpetual Free Tier offering 50 agentic requests per month and 1,000 lines of code per month for Java transformation, with no time limit on the free tier itself.

How much does Amazon Q Developer Pro cost?

The Pro Tier costs $19 per user per month, billed monthly, with increased usage limits, admin controls, and IP indemnity.

Does Amazon Q Developer work outside AWS?

It works in general IDEs and can assist with code in any project, but its most differentiated features — AWS Console Q&A, CLI generation, and pricing lookups — are AWS-specific and add less value for non-AWS codebases.

Can Amazon Q Developer upgrade legacy applications automatically?

Yes, it includes automated code transformation capabilities specifically for upgrading legacy Java and .NET applications.

What happens if I exceed my Pro tier code transformation limit?

Usage beyond the pooled 4,000 lines of code per user per month is billed at $0.003 per line of code submitted for transformation.

What is Amazon Q Developer's G2 rating?

As of August 2026, Amazon Q Developer holds a 4.6 out of 5 rating on G2 based on 51 reviews.
