Amazon Q Developer is worth using today if your team lives on AWS or has Java and .NET code to upgrade, but it is a risky long-term pick: AWS has announced it will discontinue support for the IDE plugins on April 30, 2027 and recommends Kiro instead. It is a coding assistant with inline suggestions, chat, agentic tasks (features, tests, documentation, reviews, refactoring, upgrades), vulnerability scanning and CLI help, and it also answers cost, architecture and incident questions inside the AWS Console, Slack and Microsoft Teams. It runs in JetBrains, VS Code, Visual Studio and the command line, with Eclipse and GitHub in preview. There is a free tier and a $19 per user per month Pro tier.

Best for

Who it is for: AWS-heavy teams, platform and cloud engineers, and organizations modernizing Java or .NET apps that want an assistant tied to AWS accounts. Who it is NOT for: teams outside AWS, anyone wanting a tool with a clear multi-year IDE roadmap (given the announced 2027 plugin end of support), or heavy daily agentic users who will exceed 50 free requests.

Key features

01

Code assistance

Suggestions from snippets to full functions, inline chat, CLI completions and natural-language-to-bash.

02

Agentic tasks

Multistep work such as implementing features, writing tests and documentation, code reviews, refactoring and upgrades.

03

Security scanning

Finds vulnerabilities and suggests fixes, and can generate unit tests.

04

Code transformation

Java version upgrades and .NET porting from Windows to Linux, metered in lines of code.

05

AWS guidance

Answers questions on costs, architecture, incidents and networking in the AWS Console, Slack and Microsoft Teams.

06

Private repository context

Connect your own repositories for more relevant recommendations.

Pros and cons

Pros

  • Free tier is permanent, not a time-limited trial
  • Understands AWS accounts, costs and services, so cloud questions get grounded answers
  • Automated Java and .NET transformation targets tedious modernization work
  • Pro tier includes IP indemnity and an admin dashboard for managed teams
  • Works across several IDEs, the CLI, and chat apps like Slack and Teams

Cons

  • AWS states it will end support for Amazon Q Developer IDE plugins on April 30, 2027 and recommends Kiro, so plan a migration
  • Free tier gives only 50 agentic requests a month, little for daily use
  • Pro does not publish a numeric agentic request cap, and limits may be adjusted by AWS
  • Transformation overage at $0.003 per line can add up on big codebases (50,000 lines used against a 40,000 pool costs $30 per AWS's example)
  • Least useful for codebases and teams outside AWS

Frequently asked questions

Is Amazon Q Developer free?

Yes, the Free tier gives 50 agentic requests and up to 1,000 lines of transformed code per month at no cost.

How much is Pro?

$19 per user per month. It adds an admin dashboard, IP indemnity, 4,000 pooled transformation lines per user monthly, and automatic data-collection opt-out.

Is Amazon Q Developer being discontinued?

AWS's product page says it will discontinue support for the IDE plugins on April 30, 2027 and recommends Kiro. It did not describe what happens to other surfaces such as the Console, so check AWS for details.

What happens if I exceed the transformation limit?

On Pro, usage beyond the pooled allotment is $0.003 per line submitted. Free tier lists no overage charge.

Does it only work for AWS code?

No, it works in general projects, but its Console, cost and account-aware features matter mostly if you use AWS.
