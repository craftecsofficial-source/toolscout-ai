MemoryPlugin is a strong pick for heavy users of several AI assistants who are tired of re-explaining themselves, and it is not worth paying for if you only use one assistant whose built-in memory already works for you. It is a third-party memory layer: you save memories manually or let the AI save them, sort them into buckets such as work, personal and projects, import your old chat history, and the tool feeds the relevant context into new conversations. Access is through a browser extension (Chrome, Safari and mobile), a hosted MCP server for tools like Claude Code and Cursor, a Custom GPT, a TypingMind plugin and an API. Smart Memory picks which memories to inject; the vendor says this cuts injected tokens by up to 90%, which we did not verify. There are two paid tiers billed yearly, a 7-day trial that needs a card, and a lifetime option whose price the pricing page did not show today.

Best for

Good for people using ChatGPT, Claude, Gemini and coding agents side by side, researchers and developers who want project context available everywhere, and teams sharing buckets on Pro. Not for people who use one assistant, anyone uncomfortable storing personal context with a third-party service, or buyers who want a monthly or free plan.

Key features

01

Cross-tool memory

A single memory store available in 21+ AI tools including ChatGPT, Claude, Gemini, Grok, DeepSeek, Perplexity, Mistral, Cursor and Claude Code.

02

Buckets and memory suggestions

Memories are grouped into buckets, and suggestions flag duplicates and outdated facts for your approval.

03

Chat history import

Imports from ChatGPT, Claude, Gemini, TypingMind, Grok and DeepSeek, with meaning-based search. Core is limited to your last 500 conversations.

04

Smart Memory

Injects only the relevant memories per conversation rather than everything.

05

Integrations

Browser extension, hosted MCP server, Custom GPT, TypingMind plugin and open API.

06

Files and images

Ask questions over uploaded PDF and Word files, store image memories and keep version history.

07

Pro extras

Shared buckets for teams, conversation summaries, monthly insights, usage analytics and an early-beta knowledge graph.

Pros and cons

Pros

  • One memory spans a very wide set of tools, including coding agents via MCP, which built-in memories cannot do.
  • History import turns years of old chats into searchable context without re-entering anything.
  • Buckets and suggestions keep memory organized and let you remove stale or duplicate facts.
  • Trial plus a 14-day refund lowers the risk of testing it.

Cons

  • No monthly option was visible, so you commit to a year or a lifetime payment.
  • Core limits history import to 500 conversations; unlimited import needs Pro at double the price.
  • The trial needs a credit card, and lifetime purchases have no trial and a support-based refund.
  • Your personal context lives with a third-party service; check its data handling before importing sensitive chats.
  • The pricing page shows struck-through reference prices ($180 and $300) without explaining them, and its description of the macOS sync app is inconsistent (coming soon versus available).

Frequently asked questions

How much does MemoryPlugin cost?

Core is $89/year and Pro is $180/year. A lifetime plan exists, but its price was not shown on the pricing page today.

Is there a free plan?

No free plan was shown; there is a 7-day free trial that requires a card, cancellable before day 7.

What is the difference between Core and Pro?

Pro adds unlimited chat history import, shared buckets, summaries, insights, usage analytics and an early-beta knowledge graph. Core caps import at your last 500 conversations.

Can I get a refund?

Yes, within 14 days of a charge through Settings > Account. Lifetime purchases go through support.

Which tools does it work with?

The site lists 21+ including ChatGPT, Claude, Gemini, Grok, DeepSeek, Perplexity, Mistral, Cursor and Claude Code.
