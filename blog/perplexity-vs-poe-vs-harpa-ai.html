About Perplexity

Perplexity answers questions by searching the web in real time and linking the sources inline. It also offers deeper research modes and its own AI browser, Comet, across free and paid plans.

Pricing: Free plan available; Pro $20/mo ($200/yr, about $17/mo); Max $200/mo ($2,000/yr); Enterprise per seat (check the official pricing page)

  • ✓Every answer links to its sources, so claims are quick to check
  • ✓Free plan is a workable search replacement for light use
  • ✓Comet extends it from a chat box into a browser

About Poe

Poe is Quora's multi-model chat app. It puts models from OpenAI, Anthropic, Google, Meta and Mistral, plus community-made bots, behind one login, with usage metered through shared compute points.

Pricing: Free tier with limited daily use; paid subscription tiers give a monthly pool of compute points. Exact tier prices and point amounts are unverified here - see the official Poe pricing page

  • ✓One account for many frontier models, handy for side-by-side comparison
  • ✓Custom bot builder packages a prompt into a shareable bot without code
  • ✓Native apps on every major platform

About HARPA AI

HARPA AI is a Chrome extension that adds an AI sidebar to any page. It can summarize, draft, extract data, monitor pages for changes and run reusable commands, using several AI models.

Pricing: Free demo (10 web-session messages/day, 100 total command runs); paid plans from about $12/mo billed annually, a ~$240 one-time lifetime plan, and Megatoken top-ups. Prices display in local currency (EUR on our check), so confirm on the official pricing page

  • ✓Combines page-aware chat with monitors, extraction and commands in one extension
  • ✓Free demo lets you test before buying
  • ✓Lifetime plan option with your own API keys or web sessions
