About Zapier

Zapier links thousands of web apps into automated workflows without code. It has grown beyond Zaps to include Tables, Forms, Canvas, Agents, Chatbots and an MCP server and SDK that let AI tools act inside your apps.

Pricing: Free plan (100 tasks/mo); Professional from $19.99/mo (task tiers 100 to 2M/mo); Team from $69/mo; Enterprise custom

  • ✓Biggest app catalogue among no-code automation tools
  • ✓Quick to learn for non-developers
  • ✓Usable free plan and a 14-day Professional trial with no card required

About Ishi

A local-first desktop app that organizes files, automates document workflows, and hands off complex tasks to the cloud only when you explicitly approve it.

Pricing: Free tier (BYOK); one-time lifetime Pro license $49 during public beta (list price $99) — no subscription

About Autonoma

Autonoma is an open-source agentic end-to-end testing platform: AI agents run your web app in a real browser on each pull request and report failures on the PR, with no test scripts to maintain.

Pricing: Self-hosted: free (open source, BSL 1.1). Cloud pricing unverified - the official pricing page could not be fetched on 2026-10-27; check getautonoma.com/pricing
