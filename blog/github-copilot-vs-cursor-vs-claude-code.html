About GitHub Copilot

Copilot gives inline completions, chat, agent mode and a cloud coding agent inside VS Code, Visual Studio, JetBrains, Xcode, Neovim and GitHub.com, with usage-based AI credits for chat and agent work.

Pricing: Free (2,000 inline suggestions + 50 chat requests/mo); Pro $10/mo; Pro+ $39/mo; Max $100/mo; Business $19/user/mo; Enterprise $39/user/mo. Chat and agent use draws on AI credits.

  • ✓Works inside the editor you already use, with no switch needed
  • ✓Completions stay unlimited and credit-free on paid plans
  • ✓Wide model choice under one subscription

About Cursor

Cursor is a VS Code-based editor built around AI agents that edit across a codebase. Its maker Anysphere is now part of SpaceX, and since October 12, 2026 new customers buy Cursor through The X Subscription bundle with Grok.

Pricing: New customers: The X Subscription - Free ($0), Plus $8/mo, Premium $30/mo, Super $100/mo, Ultra $200/mo; Teams from $30/user/mo. Existing Pro/Teams subscribers can keep their old plans. Check the official pricing page.

  • ✓Agent-first editor with VS Code familiarity
  • ✓Multiple model providers selectable in one tool
  • ✓Free tier to try the agents

About Claude Code

Claude Code reads your codebase, edits files, runs commands and tests, and opens pull requests. It runs in the terminal, VS Code, JetBrains, a desktop app, the web, mobile, GitHub and Slack.

Pricing: Included with Claude Pro ($17/mo annual, $20 monthly), Max (from $100/mo), Team and Enterprise; also usable via Claude Console at API token rates. Not included in Free.

  • ✓Strong at multi-file, long-running refactors and migrations
  • ✓Not tied to one editor; works from the terminal or extensions
  • ✓One usage pool shared across Claude web, desktop, mobile and Claude Code
